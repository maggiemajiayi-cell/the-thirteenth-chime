# The Thirteenth Chime

A point-and-click room escape game built with SVG, HTML, CSS, and vanilla JavaScript.

Open [clockwork/index.html](clockwork/index.html) and click **Start** to watch the opening cinematic, then enter the workshop. You can skip the intro. Use **←** and **→** to turn between fixed views, and **↓** to leave a close-up. The speaker button opens the five-step BGM volume scale (0, 25, 50, 75, 100).

The wall clock's stopped time is the clue to the four number wheels on the workbench drawer. Click each wheel to advance its digit. When the drawer opens, take the brass key, select it in the inventory bar, and click the door lock. The lock rattles if you have not selected the key. All puzzle feedback appears on the objects themselves; there are no interaction popups. This is the first playable puzzle sequence, with no ending yet.
