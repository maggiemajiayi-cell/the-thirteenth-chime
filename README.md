# Clockmaker's Curse

A point-and-click room escape game built with SVG, HTML, CSS, and vanilla JavaScript.

Open [clockwork/index.html](clockwork/index.html) and click **Start** to watch the opening cinematic, then enter the workshop. You can skip the intro. Click objects to inspect them. Use **←** and **→** to turn between fixed first-person views, and **↓** to return to the previous view.

This starting version has no puzzles or inventory yet.
