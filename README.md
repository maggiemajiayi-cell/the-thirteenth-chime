# Clockmaker's Curse

A point-and-click room escape game built with SVG, HTML, CSS, and vanilla JavaScript.

Open [clockwork/index.html](clockwork/index.html) and click **Start** to watch the opening cinematic, then enter the workshop. You can skip the intro. Move the cursor over objects to find hotspots; clicking them does not show a text box in this starting version. Use **←** and **→** on the sides of the room view to turn. Click the iron door to see its close-up; **↓** at the bottom of that view returns to the room. The speaker button opens the five-step BGM volume scale (0, 25, 50, 75, 100).

The inventory bar is at the bottom and is empty in this starting version. There are no puzzles or ending yet.
